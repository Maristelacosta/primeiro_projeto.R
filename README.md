## 🎯 Sobre o Projeto
Este repositório foi criado para documentar minha jornada de aprendizado na linguagem **R**, focando em manipulação de dados, estatística descritiva e criação de gráficos elegantes com o ecossistema do `tidyverse`.

---

## 📂 Estrutura do Repositório

O projeto está organizado da seguinte forma:
* 📁 `scripts/`
  * `analise_inicial.R` — Script básico de manipulação de dados, médias e gráficos de barras com `ggplot2`.
  * `estatistica_avancada.R` — Script de estatísticas descritivas avançadas utilizando o pacote `dplyr`.
* 📄 `.gitignore` — Arquivos e pastas ignoradas pelo controle de versão do RStudio.
* 📜 `LICENÇA` — Termos de uso e distribuição do código.

---

## 🛠️ Tecnologias e Pacotes Utilizados
* **[R](https://github.com/Maristelacosta/primeiro_projeto.R/search?l=r)** (Versão recente)
* **[RStudio](https://docs.github.com/)** ou VS Code
* **[ggplot2](https://ggplot2.tidyverse.com/)** (Visualização de dados)
* **[dplyr](https://dplyr.tidyverse.com/)** (Manipulação de dados)
