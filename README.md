# primeiro_projeto.R

Este repositório contém meus primeiros scripts e análises de dados desenvolvidos na linguagem R.

## 📋 Objetivo
Documentar minha evolução nos estudos de programação em R, manipulação de dados e criação de gráficos.

## 🛠️ Tecnologias utilizadas
* **Linguagem:** R
* **Ambiente:** RStudio / VS Code

## 🚀 Como executar
1. Clone este repositório ou baixe os arquivos `.R`.
2. Abra o arquivo desejado no seu ambiente R.
3. Instale os pacotes necessários (caso utilize algum, como `tidyverse` ou `ggplot2`).
4. Execute o script.
